InventoryTrackingSystem
This project was created to strengthen my understanding of object-oriented programming and business application development in C#. The application allows users to manage inventory, search products, update quantities, and save/load inventory data using JSON files.

Concepts Practiced:
- Classes and Objects
- CRUD Operations
- Collection Management
- Searching and Filtering
- JSON Serialization
- JSON Deserialization
- File I/O
- Menu-Driven Applications
- Business Logic
- Console Applications
- System Design
- Inventory ↓ Products ↓ JSON File

The Inventory class is responsible for storing and managing products while providing search, update, save, and load functionality.

Features:
- Add Products
- Remove Products
- Update Product Quantities
- Search Products by Name
- Search Products by SKU
- Search Products by Price Range
- Display Inventory
- Save Inventory to JSON
- Load Inventory from JSON
